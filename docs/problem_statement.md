# Problem Statement

## Project Title
AI/ML Model Design for Fraud and Inefficiency Detection in Public Fund Allocation Monitoring

## Problem Definition
Public infrastructure and development projects often face issues such as fund misallocation, duplicate or overlapping assets, delayed execution, and suspicious project patterns. Traditional monitoring methods rely heavily on manual review and static reporting, which makes it difficult to detect irregularities quickly and accurately. This leads to inefficiencies, reduced accountability, and potential misuse of public funds.

## Motivation
The MPLAD scheme involves large-scale public spending across multiple projects and locations. Monitoring each project manually is time-consuming and prone to errors. There is a clear need for an intelligent system that can identify risky projects, detect anomalies, and support decision-making using data-driven insights.

## Research Gap
Existing systems often focus on simple reporting or static dashboards without integrating predictive analysis, anomaly detection, and geospatial evidence. There is limited support for identifying suspicious patterns such as over-allocation, duplicate asset reporting, and spatial overlap between project sites.

## Objectives
1. Design and implement an AI/ML-based monitoring system for risk and inefficiency detection.
2. Detect unusual funding patterns and suspicious project behaviors using anomaly detection.
3. Analyze spatial relationships between project assets to identify overlapping or suspicious activity.
4. Present risk insights through a dashboard for administrators and stakeholders.
5. Provide an explainable monitoring interface that supports decision-making rather than just raw reporting.

## Scope
The project focuses on:
- project-level fund analysis
- anomaly detection in sanctioned amounts
- geospatial risk identification
- duplicate or overlapping asset detection
- dashboard-based reporting for monitoring and review

The system is designed to act as a decision-support platform for public project oversight and accountability.

## Expected Outcome
The final system should help stakeholders identify high-risk projects and suspicious patterns early, reduce the effort required for manual inspection, and improve transparency in public fund monitoring.

## Success Criteria
- The system can ingest project and asset data.
- It identifies anomalies with meaningful risk scores.
- Dashboard users can understand risk areas and high-risk projects.
- The solution is scalable and can be extended with more datasets and models.

## Future Enhancement Roadmap
- Add more project features and real-world datasets
- Compare multiple ML models and evaluate performance
- Add filters, search, and project detailed views
- Include explainable AI for risk reasoning
- Support user authentication and role-based access
- Generate downloadable reports for audits and reviews
